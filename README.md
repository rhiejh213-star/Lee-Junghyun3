# ICN Flight Monitor

Automated monitoring of international passenger flight movements at Incheon International Airport using IIAC official open data.

**Important:** Do not commit the API key. Configure `DATA_GO_KR_SERVICE_KEY` as a GitHub Actions repository secret. Flights are never reported as actual until explicitly confirmed by the source; unverified API data is treated as unavailable.

Official API: https://www.data.go.kr/data/15140153/openapi.do
